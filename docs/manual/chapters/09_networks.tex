\chapter{Network links and current network scope}
\label{chap:networks}

\section{Purpose}
Network links connect movements at different intersections and represent travel between
stop lines.  The simulation engine supports deterministic link travel, finite link
storage and downstream receiving constraints.  Network functionality should be treated
separately from isolated-intersection lane analysis.

\section{Free-flow travel time}
For link length $L$ metres and speed $v$ km/h,
\begin{equation}
t_f=\frac{3.6L}{v}.
\end{equation}
For a 500 m link at 60 km/h, $t_f=30$ s.

\section{Finite storage}
If $N_L(t)$ is link occupancy and $K_L$ its storage,
\begin{equation}
0\leq N_L(t)\leq K_L.
\end{equation}
The simulation engine restricts upstream departure where downstream receiving storage
is unavailable.  Reported link-storage utilisation and spillback duration are therefore
operational rather than purely geometric metrics.

\section{Analytical-network status}
The event-driven analytical engine is designed to support exact travel-time shifts and
link storage in a future network extension.  Until that implementation is validated,
analytical use should not silently substitute a simplified network calculation for an
unsupported feature.
